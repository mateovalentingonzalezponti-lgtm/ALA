# ALA — Aplicando lo Aprendido

## Sobre este repositorio

Este repositorio contiene el desarrollo de **ALA (Aplicando lo Aprendido)**, una serie de actividades realizadas durante la materia **Paradigmas de Programación** de la carrera **Programador Universitario de Sistemas** en la **Universidad Nacional de Villa Mercedes (UNViMe)**.

El objetivo de ALA es aplicar de manera práctica los conceptos y conocimientos adquiridos durante la cursada, mediante diferentes actividades y ejercicios de programación.

El trabajo se encuentra organizado en diferentes **ALA**, y cada una de ellas puede estar compuesta por distintos ejercicios y actividades.

---

# Estructura de ALA

La organización general del trabajo sigue la siguiente estructura:

```text
ALA — Aplicando lo Aprendido
│
├── ALA 1
│   ├── Ejercicio 1
│   ├── Ejercicio 2
│   └── Ejercicio 3
│
├── ALA 2
│   └── ...
│
├── ALA 3
│   └── ...
│
└── ...
```

Cada **ALA** representa una instancia de aplicación de los conocimientos adquiridos durante la materia y puede contener diferentes ejercicios relacionados entre sí.

> **Estado actual:** Este repositorio contiene el desarrollo de **ALA 1** y sus respectivos ejercicios.

# Objetivos de ALA

Los principales objetivos de **Aplicando lo Aprendido** son:

1. Aplicar los conocimientos adquiridos durante la materia.
2. Resolver problemas mediante programas.
3. Practicar diferentes formas de estructurar programas.
4. Desarrollar soluciones claras y organizadas.
5. Aplicar conceptos de programación de manera práctica.
6. Mejorar progresivamente las prácticas de programación.
7. Documentar las soluciones implementadas.
8. Practicar el uso de Git y GitHub.
9. Mantener un historial de evolución del trabajo.
10. Adquirir experiencia en el desarrollo y organización de proyectos.

# Conceptos trabajados

A través de los diferentes ejercicios que componen ALA 1 se incorporan diferentes conceptos de programación.

### Programación estructurada

Organización de un programa mediante funciones y estructuras de control.

### Funciones

Creación de funciones para dividir problemas y reutilizar código.

### Objetos

Representación de entidades mediante objetos con diferentes atributos.

### Modularización

Separación del programa en diferentes archivos y módulos.

`import` y `export`

Comunicación entre diferentes módulos JavaScript.

### Validación

Control de los datos ingresados por el usuario.

### Manejo de fechas

Utilización del objeto `Date` para trabajar con fechas.

### Git

Control de versiones de los proyectos.

### GitHub

Almacenamiento remoto y seguimiento de los cambios realizados.
