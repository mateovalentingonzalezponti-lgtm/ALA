# Ejercicio 1 — JavaScript y programación estructurada

En este ejercicio se analiza el lenguaje **JavaScript**, teniendo en cuenta solamente sus características relacionadas con el paradigma de **programación estructurada**.

---

# Parte A

## 1. Generalización simbólica

Las generalizaciones simbólicas son las reglas y elementos que forman parte del lenguaje.

En JavaScript podemos encontrar:

* Variables y constantes.
* Tipos de datos.
* Operadores.
* Expresiones.
* Condicionales (`if`, `else`, `switch`).
* Estructuras repetitivas (`for`, `while`, `do...while`).
* Funciones.
* Sentencias.
* Reglas de sintaxis.

Estas reglas permiten escribir programas de una manera determinada y hacer que el código pueda ser interpretado y ejecutado correctamente.

En el caso de la programación estructurada, nos interesan principalmente las estructuras de secuencia, selección y repetición, además del uso de funciones para organizar el código.

## 2. Creencias de los profesionales

Una característica que suele considerarse una ventaja de JavaScript es que es un lenguaje bastante flexible y permite resolver diferentes tipos de problemas.

También es valorado por:

* Tener una sintaxis relativamente sencilla para comenzar a programar.
* Permitir trabajar con funciones.
* Permitir dividir el código en módulos.
* Tener una gran cantidad de documentación y recursos disponibles.
* Contar con una comunidad muy grande.
* Poder utilizarse en diferentes entornos mediante implementaciones de ECMAScript.

Estas características pueden hacer que JavaScript resulte práctico para aprender y desarrollar diferentes tipos de programas.

## 3. Valores

Los valores son los criterios que se consideran importantes al trabajar con un lenguaje.

En JavaScript pueden destacarse aspectos como:

* La reutilización del código.
* La organización.
* La facilidad para ampliar un programa.
* La legibilidad.
* La flexibilidad.

Estos valores dependen también de cómo el programador utilice el lenguaje.

## 4. Ejemplares

Los ejemplares son ejemplos o soluciones que sirven como referencia para resolver problemas similares.

En programación pueden ser algoritmos, estructuras de código o formas conocidas de resolver determinados problemas.

Por ejemplo, una función que recibe datos, los procesa y devuelve un resultado puede utilizarse como modelo para resolver otros problemas similares.

---

# Parte B

## 1. ¿Tiene una sintaxis y una semántica bien definida? ¿Existe documentación oficial?

Sí. JavaScript tiene una sintaxis y una semántica definidas mediante el estándar **ECMAScript**.

La especificación oficial establece cómo debe funcionar el lenguaje y cuáles son sus reglas.

También existe documentación oficial y documentación técnica ampliamente utilizada para consultar las características del lenguaje.

## 2. ¿Es posible comprobar el código producido en ese lenguaje?

Sí. Es posible comprobar el código de JavaScript mediante diferentes herramientas.

Por ejemplo, se pueden utilizar:

* Editores de código.
* Linters.
* Herramientas de depuración.
* Pruebas.
* Ejecución del programa para comprobar su comportamiento.

Estas herramientas permiten encontrar errores de sintaxis, problemas en el código o comportamientos que no sean los esperados.

## 3. ¿Es confiable?

JavaScript puede utilizarse para desarrollar programas confiables, pero esto depende también de cómo esté escrito el programa.

El lenguaje proporciona mecanismos como el manejo de errores, funciones, módulos y estructuras de control que ayudan a organizar el código.

Sin embargo, utilizar JavaScript no garantiza por sí solo que un programa sea confiable. También es necesario validar los datos, controlar los errores y realizar pruebas.

## 4. ¿Es ortogonal?

JavaScript presenta un cierto grado de ortogonalidad porque varias de sus características pueden combinarse entre sí.

Por ejemplo, una función puede recibir diferentes tipos de datos, utilizar estructuras condicionales o repetitivas y devolver un resultado.

Sin embargo, JavaScript también tiene algunas particularidades y excepciones debido a la evolución que tuvo el lenguaje, por lo que no se puede considerar completamente ortogonal.

## 5. ¿Cuáles son sus características de consistencia y uniformidad?

JavaScript tiene características que permiten utilizar sus elementos de manera bastante uniforme.

Por ejemplo, las funciones pueden utilizarse como valores, pasarse como argumentos y devolverse desde otras funciones.

También existen reglas definidas para los operadores, las expresiones y las estructuras de control.

A pesar de esto, JavaScript tiene algunas características que pueden resultar particulares, principalmente por mantener compatibilidad con versiones anteriores del lenguaje.

## 6. ¿Es extensible? ¿Hay subconjuntos de ese lenguaje?

Sí, JavaScript es extensible.

Se pueden crear nuevas funciones, objetos, clases y módulos para agregar funcionalidades a un programa.

También existen librerías y paquetes que permiten incorporar funcionalidades que no están implementadas directamente en nuestro código.

Además, se pueden utilizar subconjuntos del lenguaje. Por ejemplo, un programa sencillo puede utilizar solamente variables, operadores, condicionales, ciclos y funciones, sin necesidad de utilizar todas las características disponibles en JavaScript.

## 7. El código producido, ¿es transportable?

Sí, el código JavaScript puede ser transportable entre diferentes entornos que sean compatibles con el estándar ECMAScript.

Esto permite utilizar JavaScript en diferentes plataformas y entornos de ejecución.

En este proyecto se utiliza **Node.js** para ejecutar los programas.

La transportabilidad también depende de utilizar características compatibles con el entorno en el que se quiere ejecutar el programa.

---

# Conclusión

JavaScript permite trabajar con el paradigma de programación estructurada utilizando elementos como secuencias, condiciones, ciclos y funciones.

A partir del análisis realizado, se puede observar que el lenguaje tiene reglas definidas, documentación, herramientas para comprobar el código y diferentes posibilidades para organizar y ampliar los programas.

También presenta algunas características que pueden hacerlo flexible, aunque ciertas particularidades del lenguaje pueden hacer que algunos conceptos sean menos uniformes que en otros lenguajes.
